# Tutorial for MALDI mass spectrometry imaging (spatial lipidomics) data preprocessing and analysis
This tutorial provides a walk-through of preprocessing and analysing MALDI mass spectrometry imaging (MSI) data, using the mouse brain as running example but aiming at any tissue, organism and experimental design. It covers setting up the computational environments, data formats, conversion, quality control and tissue masks, peak calling, matching features across sections, normalization and batch effects, optional registration to a reference atlas (the Allen CCF in the worked example) or to histology, lipid annotation, feature selection, embedding and integration, clustering, imputation, characterization of lipid territories, case-control comparisons, and 3D reconstruction.

The tutorial is built around the public pipeline of the Lipid Brain Atlas ("The lipidomic architecture of the mouse brain", Fusar Bassini, Schede et al., *Nature* 2026), which uses uMAIA and EUCLID. For each step it also presents open-source alternatives (Cardinal, MALDIquant, METASPACE, msiFlow, DeepSlice, internal-standard quantification) and compares the choices of other published pipelines. Where a step depends on the experimental design, it covers both serial sections of stereotyped organs and independent samples (e.g. organoids, biopsies), and the normalization section compares pixel-level and cross-sample (slide, run) normalization methods with their assumptions. Appendix A documents where the Lipid Brain Atlas code differs from its Methods.
